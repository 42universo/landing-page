# Pontos turísticos de São Paulo

Página interativa para explorar 20 pontos turísticos da cidade de São Paulo, com mapa, avaliações indicativas, descrições e filtro para exibir apenas atrações gratuitas.

## Como abrir

Abra o arquivo `index.html` em um navegador. O mapa usa MapLibre GL JS e o estilo OpenFreeMap, carregados pela internet.
